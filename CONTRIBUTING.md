# Contributing

Silo does not take outside pull requests.

The reason is the licence. Silo is AGPLv3 to everyone, and the copyright is
held by one person, which is what allows it to also be licensed on other terms
to an organisation that cannot take the AGPL. Every outside contribution
would add a second copyright holder whose permission the next commercial
licence would need, so the tree stays single-authored on purpose.

Bug reports and proposals are welcome as issues. If a change is worth making,
it will be written here; a pull request will be closed unmerged, and its
contents will not be used.
