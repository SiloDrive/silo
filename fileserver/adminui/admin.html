Storage

    Libraries

    Size is logical at head — the files the head commit reaches — not bytes on disk. Every object is sealed at rest under storage.key whatever a library’s own setting says; e2ee means the server additionally cannot read it.

    Accounts

    Capabilities grant nothing on their own: the rule is a conjunction, so an account must be an admin and hold the capability. Rows on a non-admin are shown as they are, because hiding them would hide what a demotion left behind.
